## 1. 개요

### 개발 목적

대한민국 시도 단위의 공공데이터를 기반으로 의료 및 복지 인프라 공급 현황을 분석하여 지역 간 격차를 진단하고 정책적 의사결정을 보조한다.

### 해결하고자 하는 문제

- **응급의료 자원 쏠림**: 특정 대도시권으로의 응급의료 인력 및 기관 집중 현상과 이로 인한 응급환자 전원율 격차 문제를 규명한다.
- **고령화 대비 공급 불균형**: 급증하는 고령인구 대비 요양병원과 노인복지시설의 지역별 수급 격차 및 치우침 상태를 진단한다.
- **소아청소년과 인프라 붕괴**: 출산율 감소와 소아과 폐업률 간의 연관관계를 분석하여 소아의료 취약지역을 도출한다.

### 핵심 가치

- **지표 정규화 기반 진단**: 단위와 성격이 다른 복지시설 수와 요양병원 수를 Min-Max 정규화하여 상대 비교가 가능한 단일 불균형 지표를 제공한다.
- **공간 분포의 직관화**: 행정구역 GeoJSON 경계 데이터와 분석 결과 지표를 매핑하여 시도별 인프라 과부족 상태를 시각화한다.
- **동적 트렌드 분석**: 연도 구간 슬라이더를 활용해 시계열 CAGR(연평균 증감률)을 실시간 연산하여 과거 추이와 미래 인프라 수요 예측 근거를 제시한다.

## 4. 주요설계

### 데이터 파이프라인 (Data Pipeline)

1. **수집 (Collect)**: 통계청(KOSIS) API 및 공공데이터포털을 통해 시도별 요양병원 수, 노인복지시설 현황 데이터를 취득한다.
2. **전처리 (Preprocess)**: 시도 명칭 표준화 맵을 구축하여 명칭을 일괄 정제하고 분기별 데이터를 연간 평균값으로 수렴시킨다.
3. **분석 (Analysis)**: 정규화 수식을 적용하여 공급 편차 스코어를 계산하고 시계열 구간별 연평균 증감률(CAGR)을 산출한다.
4. **시각화 (Visualization)**: Streamlit 화면 상에서 사용자의 입력 매개변수에 맞춰 지도 및 Plotly 차트를 실시간 동적 렌더링한다.

### 핵심 scoring 알고리즘

서로 다른 스케일을 가진 노인복지시설과 요양병원의 상대적 공급 격차를 측정하기 위해 다음과 같은 Scoring 알고리즘을 사용한다.

1. **지표 정규화 (Min-Max Normalization)**
    - 복지시설 정규화 지수: $W_{norm} = \frac{W - W_{min}}{W_{max} - W_{min}}$
    - 요양병원 정규화 지수: $H_{norm} = \frac{H - H_{min}}{H_{max} - H_{min}}$*(단, $W$는 해당 연도의 복지시설 수, $H$는 요양병원 수이며 $min$과 $max$는 당해 연도 전국 시도 중 최솟값과 최댓값을 의미한다.)*
2. **인프라 치우침 지수 (Imbalance Index)**
    
    $$
    I = W_{norm} - H_{norm}
    $$
    
    - **$I > 0$ (양수)**: 복지시설 정규화 수준이 더 높은 복지 인프라 치우침 지역을 의미한다.
    - **$I < 0$ (음수)**: 요양병원 정규화 수준이 더 높은 의료 인프라 치우침 지역을 의미한다.
    - **$I \approx 0$ (0에 수렴)**: 두 인프라의 공급 비율이 상대적으로 균형을 이루는 지역을 의미한다.

## 6. 데이터 출처

대시보드 분석에 활용된 원천 데이터셋의 출처는 다음과 같다.

- **통계청 국가통계포털 (KOSIS)**: 시도별 주민등록인구 현황 및 연도별 인구 통계 데이터
- **보건복지부 (공공데이터포털)**: 전국 노인복지시설 설치 및 운영 현황 데이터
- **국토교통부 (공간정보포털)**: 대한민국 시도 경계 행정구역 공간 정보 (GeoJSON)
